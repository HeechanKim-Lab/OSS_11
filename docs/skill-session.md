## 세션 1 — `generate` 모드 초기 PRD 12개 문서 생성 (`2026-11-01`)

### 1. 사용자 초기 프롬프트
> 우리 연구실의 Micro-Tom 토마토 근권 16S 앰플리콘 파이프라인(`modules/00`~`13`)을 돌리기 전에, 대학원생들이 매니페스트 오타랑 음성대조군(NTC) 오염 기준 때문에 매번 서버에서 에러가 나서 시간을 버려. 원시 FASTQ 업로드 없이 브라우저에서 3초 만에 사전 검증하고 바로 실행 명령어를 뽑아주는 웹 워크벤치를 만들려는데 뭐부터 검증하고 준비해야 할지 정리해줘.

### 2. Skill 트리거 및 1단계 입력 수집 (5문항 일괄 확인)
- `"뭐부터 검증하고 준비해야 할지 정리해줘"` 표현을 통해 `'PRD'`라는 단어 없이도 `lean-prd` Skill의 `generate` 모드가 정상 트리거됨.
- Skill이 한 턴에 질문한 5개 항목과 사용자 답변 요약:
  1. **타깃 고객과 첫 10명**: 소속 원예·미생물 연구실 대학원생 4명 + 공동연구 미생물생태학 연구실 6명 (`Persona-01`~`Persona-10`)
  2. **현재 대안과 한계**: 수동 TSV 작성 후 `qiime tools import` 직접 실행(오류 발견까지 1~2시간 지연), R `decontam` 수동 실행
  3. **팀 현황 및 가용 시간**: 본인 1인 프로젝트 (`주 20시간 = 0.50 FTE`), Python/R/Bash 및 GitHub Actions 보유, 연구실 포닥(`Persona-02`) 도메인 자문 가능
  4. **제약 조건**: 8주(`MS0`~`MS3`), 월 예산 5만 원 이하(무료 티어 우선), 공공 연구과제 보안 규정상 **원시 FASTQ 외부 클라우드 업로드 금지**
  5. **사전 확보 데이터**: `amplicon_logs/01`~`11` 연구실 파이프라인 트러블슈팅 기록 및 10명 페르소나 시나리오 피드백

### 3. BML 역순 생성 및 1차 `validate_prd.py` 검증 결과
- 생성 순서: `01·02`(가설·고객) → `05`(지표) → `03·04`(MVP·요구사항) → `06`(실험) → `07·08`(팀·스택) → `09`(마일스톤) → `10`(리스크·Pivot) → `11·00`(BML 로그·개요)
- 1차 `validate_prd.py` 실행 시 발견된 오류 및 해결:
  1. `FAIL [milestone] MS0: No-Go가 가리키는 P01, P10 가 10 §3에 없음` → `09-milestones.md`에서 페르소나 ID를 `P01~P10`으로 표기해 Pivot 옵션(`P1`~`P4`) 정규식(`\bP\d+\b`)과 충돌함. 페르소나 표기를 `Persona-01`~`Persona-10`으로 수정하여 해결.
  2. 초기 초안이 페르소나 인터뷰에 있던 `"600 DPI TIFF 그래프 내보내기"`를 `03` §3 `In`에 포함시킴 → `SKILL.md` 3단계에 `"피드백 ≠ 가설: 어떤 H#를 측정하는지 답할 수 없으면 Out으로 이동"` 규칙을 보강한 뒤 재생성하여 `Out`으로 분리.
- **사람 검토 반영 (`11-bml-log.md` 검토 메모 5건 커밋 `6f56d21`)**:
  - `08-tech-stack.md` 백엔드를 클라우드 업로드 서버에서 **Zero-Upload 클라이언트 검증 + 로컬 `run_pipeline.sh` CLI 브리지(`ADR-1`)**로 변경, NSM을 `"주간 Pre-flight QC 통과 후 파이프라인 스니펫 실행 건수"`로 정교화.
