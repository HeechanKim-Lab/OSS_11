## Cycle 0 — 초기 가정 (2026-11-01)

- **기본 가정 (사용자 미응답 항목)**: 없음 — 입력 수집 5문항 모두 답변 완료 (`1인 팀·주 20시간(0.5 FTE)`, `월 예산 5만 원 이하(무료 티어 우선)`, `기간 8주(MS0~MS3)`, `첫 10명 = 소속 원예·미생물 연구실 및 공동연구자(Persona-01~Persona-10)`, `기존 Micro-Tom 근권 파이프라인(modules/00~13) 코드베이스 재사용 및 외부 클라우드 원시 FASTQ 업로드 금지`).
- **가설 위험도 스냅샷**:
  1. `H2` (솔루션 — Pre-flight QC 추천 파라미터 수락률 ≥ 60%): 불확실성 4 × 치명도 5 = **20점 (1순위)**
  2. `H3` (리텐션 — 3D PCoA · 적응형 Decontam 기반 D14 코호트 리텐션 ≥ 50%): 불확실성 3 × 치명도 4 = **12점 (2순위)**
  3. `H1` (문제 — 최근 3개월 내 매니페스트·오염 기준으로 재실행 2회 이상 비율 ≥ 70%): 불확실성 2 × 치명도 5 = **10점 (3순위)**
  4. `H4` (성장 — QC 인증 리포트 공유율 ≥ 20%, K ≥ 0.25): 불확실성 4 × 치명도 2 = **8점 (4순위)**
- **사전 보유 근거 데이터**:
  - `amplicon_logs/01`~`11`: Micro-Tom 토마토 근권 16S 파이프라인 수행 과정에서 Casava 파일명 불일치, Cutadapt 수율 저하, 음성대조군(NTC) 오염 ASV 제거 기준, LinDA 영과잉 통계 모델 선정 이슈가 실제로 반복 발생함.
- **MS0 1순위 실행 계획**: `E1` (`H2` Wizard of Oz + Pre-flight 매니페스트 검증 워크벤치) 및 `E2` (`H1` 10명 다중 페르소나 인터뷰) 동시 착수.

## Cycle 1 — 2026-11-12 — 대상 가설: H2 (병행 H1)

- **가설(원문 그대로 인용)**:
  - `H2`: "우리는 같은 연구자가 매니페스트와 기초 수율 정보를 입력한 뒤 AmpliconSight가 제시한 Pre-flight QC 진단 및 추천 파이프라인 파라미터(`run_pipeline.sh` 스니펫)를 수락해 실행할 것이라고 믿는다. **M2** Pre-flight QC 추천 수락률이 **60% 이상**이면 참이다."
  - `H1`: "우리는 16S 앰플리콘 시퀀싱을 수행하는 대학원생·연구원이 파이프라인 실행 직전 매니페스트 포맷 오류와 오염 제거 기준 설정 때문에 최근 3개월 내 2회 이상 재실행 지연을 겪었다고 믿는다. **M1** 인터뷰 문제 확인율이 **70% 이상**이면 참이다."
- **Build**:
  - `web/index.html`에 Casava 1.8 매니페스트 검증기, 추천 파라미터 카드, "추천 수락(스니펫 복사)" / "직접 수정(거절)" 버튼 구현 (2일 소요).
  - `amplicon_platform/core.py` TDD 핵심 함수 5종 구현 (PR `#25`) 및 5 영업일(`11/04`~`11/10`) 동안 연구자 14명 대상 Pre-flight QC WoZ 운영 (`experiments/cycle-1/woz-log.csv`).
  - 10명의 다중 페르소나(`Persona-01`~`Persona-10`) 시나리오 코드 실행 및 심층 인터뷰 수행 (`experiments/persona_feedback_10_users.json`).
- **Measure**:
  - **주 지표 `M2` (Pre-flight QC 추천 수락률)**: 총 65세션 중 `source=fallback` 2건(`R4` 규정에 따라 제외)을 뺀 유효 노출 **63건 중 52건 수락 = 82.54%** (`experiments/cycle-1/woz-log.csv`).
  - **병행 지표 `M1` (인터뷰 문제 확인율)**: 10명 중 **8명(80.0%)**이 최근 3개월 내 매니페스트 오타·오염 기준 문제로 2회 이상 재실행 지연을 겪었다고 응답 (`experiments/persona_feedback_10_users.json`).
  - **가드레일 `G1`, `G2`**: 첫 QC 완료 시간 중앙값 **G1 = 3.9분** (234초, 기준 ≤ 5.0분 충족) · 첫 실행 성공률 **G2 = 94.2%** (49/52, 기준 ≥ 85% 충족).
  - **정성 피드백 (거절 11건 사유 분석)**: ① `"음성대조군(NTC)에서 어떤 ASV가 왜 제거되는지 한 줄 근거 툴팁이 없어서"` (6건, `Persona-01`·`Persona-07`) ② `"R1/R2 파일명 오타를 찾았을 때 원클릭으로 치환해 주는 자동 수정 버튼이 있으면 좋겠다"` (3건) ③ `"특수 프라이머(ITS2) 길이 기준 차이"` (2건).
- **사전 임계값 대조**:
  - `E1` (`M2`): 통과 ≥ **60%** / 실패 < **35%** (`06` §3) → 실측 **82.5%**로 **통과**
  - `E2` (`M1`): 통과 ≥ **70%** / 실패 < **40%** (`06` §3) → 실측 **80.0%**로 **통과**
  - Pivot 트리거 `T1`~`T5` 해당 사항 없음.
- **Learn**:
  1. 연구자들은 원시 FASTQ 업로드 없이 브라우저에서 즉시 매니페스트 오류를 잡고 `run_pipeline.sh` 명령어를 생성해 주는 워크플로우를 매우 높게 수용했다(`M2 = 82.5%`). 특히 CLI 숙련자(`Persona-09`)와 스타트업 CTO(`Persona-04`) 모두 "클라우드에서 무거운 DADA2를 직접 돌리지 않고 Pre-flight QC + CLI 브리지로 설계한 것이 비용과 보안 면에서 정답"이라고 확인해 주었다.
  2. 다만 추천을 거절한 11건 중 9건(81.8%)이 **알고리즘 자체의 불신이 아니라 "왜 이 임계값(0.1 vs 0.5)에서 특정 ASV(`Ralstonia`)가 오염으로 분류됐는지 설명 부족" 및 "오타 자동 치환 버튼 부재"** 때문이었다. 따라서 `MS1` 자동화 시 이 두 가지를 `FR8`로 추가하면 수락률과 리텐션을 동시에 높일 수 있다.
- **결정**: **Persevere** → `MS0` 최종 통과 및 `MS1` (Feature Flag 자동화 & 2주 코호트 리텐션 검증) 착수.
