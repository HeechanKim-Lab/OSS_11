## 2. Pivot 트리거

정성적 느낌("반응이 미지근함")이 아니라 **사전 합의된 정량 숫자 조건**만 트리거로 인정한다.

| 트리거 | 조건 | 연결 옵션 |
|---|---|---|
| T1 | M2 Pre-flight QC 추천 수락률 < 35% (노출 60건 이상) 1회 발생, 또는 35~60% 회색 지대 2사이클 연속 | P1 |
| T2 | M1 인터뷰 문제 확인율 < 40% (N=10), 또는 MS2 타 대학원 신규 코호트에서 < 40% 재현 | P2 |
| T3 | M3 D14 코호트 리텐션 < 30% (Variant A 정적 로그 대조군보다 낮음) 2사이클 연속 | P3 |
| T4 | 추천 거절 사유 1위가 "웹 브라우저를 거치지 않고 터미널에서 바로 검사하고 싶다"로 50% 이상 차지 | P1 또는 P3 |
| T5 | Guardrail G1 첫 QC 완료 시간 중앙값 > 5.0분이 2주 연속 지속 (UI가 오히려 연구자를 지연시킴) | P1 |

## 4. Kill 조건

Pivot으로도 구제할 수 없어 프로젝트를 즉시 종료(Kill)해야 하는 조건:

1. **문제 자체의 부재**: 대학원생 세그먼트(`A`)와 코어 퍼실리티 세그먼트(`B`, `P2` 적용 후) 양쪽 모두에서 **M1 문제 확인율 < 40%**가 연속 관측될 때 (즉, 현장에서 매니페스트나 오염 제거로 인한 재실행 고통이 실제로는 미미함).
2. **솔루션 수용 불가**: `P1`(단순 CLI 생성기)과 `P3`(CLI 내장 플러그인)를 모두 시도했음에도 **M2 추천 수락률 < 35%** 또는 **G2 첫 실행 성공률 < 60%**에 머물 때.
3. **지속 가능성 부재**: MS3 종료 시점까지 **M3 D14 리텐션 < 25%**, **M5 공유율 < 5%**, **M4 기관 도입 의향 < 10%**가 동시에 발생하여 학술적·상업적 확산 경로가 전무할 때.
