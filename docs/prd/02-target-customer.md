## 2. 얼리어답터 페르소나

### 김지훈 (석사 1년차, 원예생명공학 Wet-lab 대학원생 — Primary)

- 상황: Micro-Tom 토마토 근권 식염 스트레스 16S 샘플 36개의 시퀀싱 결과(FASTQ 72개 파일)를 방금 메일로 받음. 금요일 연구실 미팅 전까지 QIIME2 + DADA2 + LinDA 분석 결과를 교수님께 보고해야 함.
- 현재 해결 방법: 선배가 물려준 `run_pipeline.sh`를 돌리려다 `manifest.tsv`의 `_R1_`/`_R2_` 오타로 2시간 만에 에러 발생. 음성대조군(NTC)에서 나온 `Ralstonia` 리드를 지워야 할지 몰라 그대로 뒀다가 미팅에서 재분석 지시를 받음.
- 불만: "리눅스 터미널에서 에러 로그 읽는 게 제일 무서워요. 돌리기 전에 내 파일이랑 설정이 맞는지 3초 만에 확인해 주는 웹 화면이 있으면 좋겠어요."
- 트리거 순간: 시퀀싱 업체에서 FASTQ 다운로드 링크 메일을 받은 직후.
- Aha moment: 브라우저에 매니페스트 텍스트를 붙여넣자마자 2번째 줄 R2 파일명 오타를 짚어주고, 검증 통과 후 바로 실행 가능한 `bash pipeline/run_pipeline.sh` 명령어 한 줄을 복사해 서버에서 한 번에 성공했을 때.

### 박소연 (박사후연구원, 토양 미생물 생태학 — Secondary)

- 상황: 경주·밀양·익산 3개 지역 샘플 60개의 베타 다양성(PCoA)과 LinDA 차등 풍부도를 비교 중.
- 불만: "R에서 매번 파라미터 바꿔가며 2D 플롯 다시 그리기 번거로워요. 브라우저에서 Feature Flag만 켜면 3축(PC3) 회전과 적응형 Decontam 효과를 바로 비교하고 싶어요."
- 주의: 박소연 유형은 검증 완료 후 **재현 가능한 CLI 파라미터 스니펫과 JSON 감사 로그**가 함께 제공되어야 신뢰한다.
