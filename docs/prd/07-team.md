## 3. 채용 / 외주 우선순위

1. **미생물 생태학 도메인 자문 (MS0~MS1, 최우선)** — 이유: `H2`(추천 파라미터 수락)의 핵심은 연구자가 추천된 Cutadapt·Decontam 임계값을 학술적으로 신뢰하는 것이다. 소속 연구실 포닥(`P02`)의 기준값 감수로 비용 0원에 신뢰도를 확보한다.
2. **UI/UX 온보딩 단기 외주 (MS2, 조건부)** — 이유: CLI 초보 석사생(`P01`)과 공공기관 연구사(`P07`)가 첫 화면에서 5분(**G1**) 안에 검증을 끝내지 못하면 리텐션(`H3`)이 무너진다. 예산: 1회 10만 원.
3. **시퀀싱 코어 퍼실리티 채널 자문 (MS3)** — 이유: `H4`(QC 인증 리포트 확산)는 개별 연구자 공유뿐 아니라 시퀀싱 업체 납품 안내문에 링크가 들어갈 때 폭발적으로 성장한다.
4. **백엔드 인프라 엔지니어 — 채용하지 않음** — 이유: `08-tech-stack.md` ADR-1에 따라 원시 FASTQ 클라우드 업로드를 배제했으므로 MS3까지 전담 백엔드 인력이 불필요하다.
